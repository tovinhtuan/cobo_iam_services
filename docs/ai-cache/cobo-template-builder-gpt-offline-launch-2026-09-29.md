# CoBo Template Builder GPT — offline launch

Created: 2026-09-29  
Scope: ChatGPT Custom GPT, offline authoring mode.

## Delivered

- Created **CoBo CMS Template Builder** as a private, live Custom GPT.
- Uploaded three non-secret Knowledge files: import schema v1, canonical JSON
  example, and CMS import guide.
- Enabled Code Interpreter so it can emit a downloadable JSON candidate.
- Disabled Web Search and Image Generation; no Action or external API is
  configured.
- Preview confirmed it asks for missing compliance facts rather than inventing
  them, and it labels output as a self-checked candidate rather than a CMS
  validation.

## Sharing

The active ChatGPT account only offered **Only me**. The UI stated that public
sharing is no longer available, so no external user was granted access and no
public share setting was created. The GPT has its private ChatGPT URL, which is
not recorded here.

## Follow-up

When the account/workspace enables an appropriate sharing option, set the
desired access level in ChatGPT before distributing its URL. Add the future
validate-only OAuth Action only after CoBo has a dedicated public HTTPS gateway
and the Action can be smoke-tested without CMS side effects.
